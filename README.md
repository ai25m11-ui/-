# 🎓 حاسبة تسعير خدمات الكتابة الأكاديمية
### Academic Writing Services Pricing Calculator

نظام تفاعلي عصري ومتكامل لحساب تكاليف خدمات الكتابة والبحوث الأكاديمية بالدينار العراقي (IQD)، مع إصدار فواتير رسمية ولوحة تحكم إدارية مدمجة.

---

## ✨ المميزات الرئيسية (Features)

- **⚡ تسعير فوري ودقيق**: حساب تلقائي لمختلف أنواع الأبحاث (أبحاث دراسية، مقالات علمية، رسائل ماجستير، أطروحات دكتوراه، تقارير، ترجمة، وخطط بحثية).
- **⏱️ خيارات سرعة التسليم**: دعم التسليم العادي، السريع (خلال 3 أيام)، والعاجل (خلال 24 ساعة) بنسب تسعير تلقائية.
- **🛠️ خدمات إضافية متكاملة**: إضافة وتخصيص خدمات الفحص والتدقيق (تدقيق لغوي، فحص استلال / انتحال، تصميم غلاف، إعداد مراجع، وشرائح عرض بوربوينت).
- **🧾 توليد فواتير احترافية**: إنشاء فواتير مفصلة برقم تسلسلي تلقائي، وتفقيط المبالغ، وحساب الدفعات والمبالغ المتبقية، مع إمكانية النسخ أو الطباعة المباشرة.
- **🔐 لوحة تحكم إدارية متقدمة (Admin Portal)**:
  - تعديل أسعار الخدمات والصفحات وحفظها محلياً في المتصفح (`localStorage`).
  - إدارة نسب الاستعجال وقيم الإضافات.
  - تعيين وتفعيل أكواد الخصم الترويجية (Promo Codes).
  - حماية لوحة المدير بكلمة مرور قابلة للتغيير.
  - اختصار وصول سريع للوحة الإدارة: الضغط على `Ctrl + M` أو `Ctrl + Shift + A`، أو النقر 3 مرات على شارة العنوان.
- **🎨 تصميم فاخر وجذاب**: واجهة داكنة مريحة للعين مع لمسات ذهبية ملكية، وتأثيرات جزيئات متحركة بخلفية Canvas، ومتوافقة تماماً مع جميع مقاسات الشاشات والجوالات.
- **🌐 جاهز للاستضافة المباشرة**: كود مستقل بالكامل يعمل بصفحة واحدة (HTML / CSS / JS) بدون أي اعتماديات خارجية معقدة.

## 🚀 طريقة التشغيل (Quick Start)

### 1. التشغيل المحلي:
ما عليك سوى فتح ملف `index.html` أو `writing-calculator.html` في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).

### 2. النشر عبر GitHub Pages:
1. ارفع المشروع إلى مستودع جديد على حسابك في GitHub.
2. اذهب إلى إعدادات المستودع (**Settings**) > ثم قسم **Pages**.
3. في خيار **Branch**، اختر `main` واضغط **Save**.
4. سيعمل الموقع مباشرة على الرابط: `https://<username>.github.io/<repo-name>/`.

## ⚙️ إعدادات لوحة المدير الافتراضية

- **كلمة المرور الافتراضية**: `2026`
- **كود الخصم الافتراضي**: `VIP2026` (نسبة 15%)
- **طريقة الفتح**: اختصار لوحة المفاتيح `Ctrl + M` أو النقر المتتالي 3 مرات على شارة "نظام تسعير ذكي ومعتمد".
